# Architecture

```
npx reelclaw@latest add <template>          (distribution: registry.json on GitHub main → reel project)
        │
reelclaw make <template> --flags | --props  (packages/reelclaw/src/cli/commands/make.mjs)
        │
makeReel()                                   src/core/make.mjs
  ├─ loadTemplate      loader.mjs     project templates/ → repo templates/; "reelclaw" import aliased to this engine
  ├─ parseValues       inputs.mjs     zod per input; every problem reported by flag name
  ├─ stageMedia        media/         local | direct URL (fetch) | page link (yt-dlp) → assets/<slug>-<sha256:12>.<ext>, ffprobe cached
  ├─ prepare()         template       optional async step; deriveMedia caches derived files by content hash + key
  ├─ build()           template       pure → Timeline IR (timeline.mjs builders)
  ├─ compile()         compile.mjs    IR → one standalone HyperFrames composition (reels/<name>.html)
  ├─ lintReel()        render.mjs     hyperframes lint via a scratch project
  └─ renderReel()      render.mjs     pinned hyperframes render -c reels/<name>.html → renders/<name>.mp4, duration verified
```

## Packages

- `packages/reelclaw` — the published package `reelclaw`: engine + CLI. Plain ESM JavaScript with JSDoc types (`// @ts-check`, checked by `tsc --noEmit`), no build step, Node ≥ 22 (HyperFrames' requirement). Exports `"reelclaw"` (template authoring API), `"reelclaw/core"` (engine API for commands/tools), `"reelclaw/cli"`.
- root `package.json` — npm workspaces + a `bin` so `npx github:danielhangan/reelclaw-templates <command>` works before/without an npm release. Its `dependencies` mirror the engine's (an npx git install does not install workspace deps).
- `cli/` — legacy `reelclaw-templates` npm package: a thin alias that maps v1 arguments onto `reelclaw add`.
- `packages/reelclaw/src/core/components/` — reusable building blocks on top of the clip builders (smart framing, native text, word captions, cut-outs, beats, wipes…), exported from `"reelclaw"`. See the Components table in [TEMPLATE_API.md](TEMPLATE_API.md).
- `packages/reelclaw/src/analyze/` — `reelclaw analyze` (reference video → shot list, keyframes, filmstrip) and `reelclaw scaffold` (analysis → template folder), the contributor pipeline behind `.claude/skills/new-template`.
- `registry.json` + `.claude-plugin/marketplace.json` — generated by `npm run registry` from every template; `reelclaw add` reads `registry.json` from GitHub main at runtime, and the marketplace file is how Claude Code plugins and `npx skills add` find the template skills.
- `shared/fonts/` — the one canonical TikTok Sans; `prepack` copies it into the engine package, `ensureProject()` copies it into each reel project's `assets/fonts/`.

## Decisions

- **One standalone composition per reel.** HyperFrames 0.8 renders a non-template file directly with `render -c reels/<name>.html`, so the v1 host page + `<template>` sub-composition pair is gone. Relative `../assets/` paths resolve inside the project root.
- **Local runtime files.** GSAP (`gsap` dependency) and the font are copied into `assets/vendor` / `assets/fonts`: renders never touch the network.
- **Video sound lives on the `<video>`** (`data-has-audio` + `data-volume`, HyperFrames 0.8) when a clip has a volume; otherwise the video is `muted`. Music is an `<audio>` with `data-fade-out` — no GSAP volume tweens.
- **Content-addressed staging** removes the v1 filename-collision bug class: names derive from bytes, caches are per-entry files written atomically, so concurrent `make`/`batch` runs are safe.
- **Caption fitting runs in the browser** with the real font (`fitFontSize`, a pure function serialized into the page and unit-tested in Node). Captions are measured on an off-screen clone, so captions whose window starts later are sized too.
- **Templates resolve `"reelclaw"` to the running engine** (`module.registerHooks`, falling back to `module.register`), so a reel project needs no `node_modules` to run a template and engine/template never diverge.
- **One text look per name.** `caption()` styles `tiktok-box` / `tiktok-box-dark` and the `nativeText()` component share one renderer (merged per-line boxes through an SVG goo filter), so a "TikTok box" looks the same in every template.
- **Lint** — `hyperframes lint` only accepts a project directory with `index.html`, so `lintReel` mirrors the reel into `.reelclaw/cache/lint/<name>/` with `assets/` symlinked (a junction on Windows).
- **Pinned renderer** — `HYPERFRAMES_VERSION` in `render.mjs` must match the `hyperframes` dependency. Bump both together and re-run `reelclaw validate --render`.

## Extending

- **New command:** drop `src/cli/commands/<name>.mjs` exporting `{ summary, usage, options?, rawArgs?, aliases?, run(ctx) }` (`Command` in `src/cli/main.mjs`). It is discovered automatically; `ctx` has `argv`, parsed `args`, `root` (`--project` or cwd), `cwd`, `log`, `help()`. Throw `ReelclawError(message, { hint })` for user errors.
- **New component** (preferred over a new clip type): a file in `src/core/components/` that returns ordinary clips (often an `html()` clip with its CSS and a seek-safe GSAP script), exported from `src/index.mjs`, with a `node:test` file and a row in `docs/TEMPLATE_API.md`.
- **New clip type / caption style:** add the builder in `timeline.mjs`, its emitter in `compile.mjs`, CSS in `captions.mjs`, a unit test, and a line in `docs/TEMPLATE_API.md`.
- **New template:** `reelclaw analyze <link>` → `reelclaw scaffold <id> --from analysis/<slug>`, or copy `templates/reaction-demo/`. See [CONTRIBUTING.md](../CONTRIBUTING.md).
- **Library use:** `import { makeReel, renderReel, findTemplates, validateTemplate } from "reelclaw/core"`.
